# NuN Blockchain – Node Setup Guide

This document provides step-by-step instructions to run and manage a NuN Blockchain validator node.

---

## 📦 Prerequisites

- Python 3.10+ installed
- Git
- `pip` package manager
- Internet connection (for peer discovery)
- VS Code or terminal access
